# ATLAS – Intelligenztest per Doppelklick

1. ZIP auf dem Mac entpacken.
2. Sicherstellen, dass Ollama läuft und mindestens ein **lokales** Modell installiert ist. Ohne installiertes Modell kann der Test nicht laufen. Der Starter installiert nichts automatisch.
3. `ATLAS_INTELLIGENZ_EIN_KLICK.command` doppelklicken. Wenn macOS die Datei blockiert, in den Systemeinstellungen unter Datenschutz & Sicherheit die Ausführung für diese vertrauenswürdig erhaltene Datei erlauben.
4. Nach Abschluss in `Downloads/ATLAS-Testberichte` die Datei `ATLAS-Intelligenz-Ergebnis.json` hier im Chat hochladen.

Der Starter testet höchstens zwei installierte lokale Modelle (28 Kurzaufgaben je Modell) und führt für das beste vollständig geprüfte Modell acht direkte/selbstgeprüfte Aufgaben durch. **Das kann je nach Mac und Modell deutlich länger als zehn Minuten dauern.** Die Tests können mit Strg+C abgebrochen werden.

**Keine Installation, keine API-Kosten, keine automatische Änderung deiner ATLAS-Einstellungen.** Der Starter nimmt keine ChatGPT-/Claude-Vergleichsmessung vor und darf keine 50/100 behaupten.
